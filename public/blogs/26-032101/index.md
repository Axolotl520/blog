## 一、命题背景

### 1.1 原始命题
本次集成电路创新大赛·北方华创命题赛道——**拓扑优化专项赛**，要求针对半导体装备中的关键热处理环节进行温控结构优化设计。

### 1.2 应用背景
在半导体制造工艺中，金属材料的晶粒退火和再结晶过程对温度场的均匀性和温控精度有严格要求。加热不均匀会导致材料内部应力集中，影响最终器件性能。因此，如何设计出高效的温控结构是半导体装备制造的核心痛点之一。

## 二、问题定义

### 2.1 研究对象
- **几何尺寸：** φ5 × 15 mm 圆柱形钨坯（W 材料）
- **工艺流程：** 热处理 → 升温 → 保温 → 冷却
- **核心问题：** 通过拓扑优化方法设计温控结构，提升温度场均匀性并满足工艺时间约束

### 2.2 物理现象
| 现象类型 | 描述 |
|---------|------|
| 热传导 | 钨坯内部热量传递，遵循傅里叶定律 |
| 对流换热 | 周围介质（气体/液体）与工件表面的换热 |
| 辐射换热 | 高温下的表面辐射损失（是否需要计入待确认） |

## 三、优化目标与约束

### 3.1 可能的优化目标（需要与命题方确认优先级）

**目标 A：温度均匀性优先**
$$ \min f_1 = \max_{x,y,z,t} T(x,y,z,t) - \min_{x,y,z,t} T(x,y,z,t) $$
即最小化整个工艺过程中钨坯内部的最大温差

**目标 B：时间效率优先**
$$ \min f_2 = t_{heating} + t_{holding} $$
即最短总工艺时间

**目标 C：能耗最优**
$$ \min f_3 = \int_0^{t_{end}} P(t) dt $$
即最小化加热能耗

**目标 D：多目标综合**
$$ \min F = w_1 \cdot \tilde{f}_1 + w_2 \cdot \tilde{f}_2 + w_3 \cdot \tilde{f}_3 $$
其中 $\tilde{f}_i$ 为归一化后的目标值，$w_i$ 为权重系数

### 3.2 工程约束
1. **体积分数约束：** 优化后材料保留率 ≥ X%（如 50%）
2. **对称性约束：** 保持轴对称或平面对称，便于实际加工
3. **最小特征尺寸：** 防止出现不可加工的微小结构（如壁厚 ≥ 0.5 mm）
4. **边界条件约束：** 加热源位置、散热面位置固定或可变？
5. **工艺要求约束：** 
   - 升温速率 ≤ X °C/min（避免热冲击）
   - 保温温度波动 ≤ ±Y °C
   - 保温时间 ≥ Z min

### 3.3 设计变量
拓扑优化的设计变量通常是每个有限元单元的材料密度 $\rho_e ∈ [0, 1]$：
- $\rho_e = 1$ 表示该位置为实体材料
- $\rho_e = 0$ 表示该位置为空腔（或被其他介质填充）

## 四、数学模型

### 4.1 控制方程
瞬态传热方程（能量守恒）：
$$ \rho c_p \frac{\partial T}{\partial t} = \nabla \cdot (k \nabla T) + Q $$

其中：
- $ρ$：密度
- $c_p$：比热容
- $k$：导热系数
- $Q$：内热源项（加热元件）

### 4.2 边界条件
需要考虑以下几种：
1. **狄利克雷边界（温度边界）：** $T = T_{boundary}$
2. **诺伊曼边界（热流边界）：** $-k \frac{\partial T}{\partial n} = q$
3. **对流边界：** $-k \frac{\partial T}{\partial n} = h(T - T_{ambient})$
4. **辐射边界：** $-k \frac{\partial T}{\partial n} = \epsilon \sigma (T^4 - T_{ambient}^4)$

### 4.3 优化问题表述
$$
\begin{aligned}
& \underset{\boldsymbol{\rho}}{\text{minimize}} & & f(\boldsymbol{\rho}, T(\boldsymbol{\rho})) \\
& \text{subject to} & & V(\boldsymbol{\rho}) ≤ V_{max} \\
& & & K(\boldsymbol{\rho}) T(\boldsymbol{\rho}) = F(\boldsymbol{\rho}) \\
& & & 0 < \rho_{min} ≤ \rho_e ≤ 1, \quad e = 1, \dots, N
\end{aligned}
$$

## 五、研究方法与技术路线

### 5.1 总体方案
采用 **"DOE 参数扫描为主 + 机器学习辅助"** 的双层策略：

```
┌─────────────────────────────────────┐
│         DOE 参数扫描                  │
│  ┌───────────────────────────────┐  │
│  │  建立参数化的 COMSOL 仿真模型    │  │
│  │  → 设置设计变量空间            │  │
│  │  → 生成样本点（拉丁超立方等）   │  │
│  │  → 批量运行仿真，采集数据      │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────┐
│         ML 辅助（可选）               │
│  ┌───────────────────────────────┐  │
│  │  用仿真数据训练代理模型        │  │
│  │  → 预测新参数的性能           │  │
│  │  → 指导 DOE 采样或作为 RL 环境   │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

### 5.2 COMSOL 仿真部分（责任人：A）
1. **几何建模：** 参数化圆柱 + 候选加热/散热区域
2. **物理场设置：** 固体传热 + （可能需要流体传热）
3. **优化模块：** SIMP 法或水平集法进行拓扑优化
4. **参数化扫描：** 批量计算不同设计参数的响应

### 5.3 强化学习部分（责任人：B）
*注：已放弃 PPO 路线，待定替代方案*

**可能的方向：**
- 使用 SAC/TD3/DDPG 等 off-policy 算法
- 状态空间：当前温度场分布、时间步、剩余预算等
- 动作空间：调整加热功率分布、切换散热策略等
- 奖励函数：负的温度偏差 + 时间惩罚 + 能耗惩罚

或者：
- **纯监督学习 + DOE：** 用 DOE 数据训练回归模型 / 分类模型，不做真正的 RL

**待决策：是否真正引入 RL？还是仅做参数扫描 + 数据挖掘？**
