# T287419 05-23-C02-猴子吃桃问题(L4)

## 题目描述

猴子第1天摘下若干个桃子，当即吃了一半，还不过瘾，又多吃了一个。第2天早上又将剩下的桃子吃掉一半，又多吃了一个。以后每天早上都吃了前一天剩下的一半另加一个。到第n天早上想再吃时，就只剩下一个桃子了。求第1天共摘了多少个桃子。

## 输入格式

输入占一行，为一个正整数n，1≤n≤20。

## 输出格式

输出占一行，为第1天摘下的桃子数。

## 输入输出样例 #1

### 输入 #1

```
10
```

### 输出 #1

```
1534
```
